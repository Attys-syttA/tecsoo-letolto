# Support

## Support mukodes

A TecsoLetolto nem kuld automatikusan hibajelentest, es nem tartalmaz SMTP jelszot.

A `Support` funkcio:

1. osszeallit egy rovid hibajelentest;
2. elonezetben megmutatja;
3. a felhasznalo ellenorzese utan az alapertelmezett levelezoprogramot nyitja meg `mailto:` linkkel.

## A hibajelentes tartalma

- program verzio;
- Windows verzio;
- yt-dlp verzio, ha ismert;
- FFmpeg verzio, ha ismert;
- utolso hiba kategoriaja es rovid leirasa;
- letoltesi mod;
- idopont;
- roviditett link;
- utolso relevans naplosorok.

## Ami nem kerulhet bele

- jelszo;
- token;
- cookie;
- teljes kornyezeti valtozo lista;
- bejelentkezesi adat;
- SMTP credential.
