# TecsoLetolto felhasznaloi utmutato

## Mire valo?

A TecsoLetolto olyan Windows alkalmazas, amellyel a felhasznalo jogszeruen mentheto online video- vagy hangtartalmat tud sajat gepere menteni.

## Mire nem valo?

A program nem hivatalos YouTube alkalmazas, nem kerul meg DRM-et, nem kezel bejelentkezest, cookie-t, elofizeteses vagy zart tartalmat.

## Jogszeru hasznalat

A program csak olyan tartalom mentesere hasznalhato, amelyhez a felhasznalonak joga van. Ilyen lehet sajat tartalom, engedellyel letoltheto tartalom, kozkincs vagy oktatasi/teszt celu tartalom. A program nem hasznalhato jogosulatlan hozzaferesre, DRM megkerulesere vagy elofizeteses/zart tartalmak megszerzesere.

## Alap hasznalat

1. Illeszd be a linket.
2. Valassz mentési mappat, vagy hagyd uresen a Windows Letoltesek mappahoz.
3. Adj meg fajlnevet, vagy hagyd uresen az automatikus nevhez.
4. Valaszd ki, hogy csak hangot vagy videot is szeretnel.
5. Kattints a `Letöltés indítása` gombra.

## Hibak es support

Hiba eseten a program rovid magyar uzenetet mutat. A `Support` gomb hibajelentes-elonezetet keszit, amelyet kuldes elott ellenorizhetsz.
